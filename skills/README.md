# Skills

[Agent Skills](https://agentskills.io) for constraint and optimisation solvers and
modelling frameworks. Install with `npx skills add DCP-Bench/DCP-Bench-Open`.

## Catalog

| Skill | Path | Description |
|---|---|---|
| `add-solver` | [add-solver](add-solver) | Creates and tests an agent skill for a constraint or optimisation solver or modelling framework (CP, SAT, MaxSAT, SMT, MIP, ASP, CLP; e.g. Choco, Gurobi, JuMP, MiniZinc). |
