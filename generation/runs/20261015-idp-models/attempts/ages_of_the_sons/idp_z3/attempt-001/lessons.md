Multi-variable quantifiers (`? a, b, c in Age:`, `! a, b, c in Age:`) parse and solve in IDP-Z3 0.12.1.
Successive "I need more information" statements can be encoded as existence of another candidate triple that shares the known quantity (product, then sum), with no counting needed.
The ages puzzle has no instance fields: the instance JSON is an empty object, and the single example is accepted.
