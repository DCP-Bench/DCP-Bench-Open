Rectangular deck, containers cuboid in a single layer -> left, right, bottom, top IntVars per container as edge boundaries, 0-based: left and bottom are the lower edges, right = left + extent_x and top = bottom + extent_y are the exclusive upper edges; left in 0..deck_width, bottom in 0..deck_length.
Containers are positioned parallel to the sides of the deck -> boolean turned_i per container; the container is either width along the deck width and length along the deck length, or turned by 90 degrees (extent_x = length, extent_y = width); element over {width, length} and {length, width}.
Containers must not overlap -> redundant diffN(left, bottom, extent_x, extent_y, true) plus, for each pair, one of four options: left_j - right_i >= sep, left_i - right_j >= sep, bottom_j - top_i >= sep, bottom_i - top_j >= sep (each reified, sum >= 1).
Certain classes constrained to be separated by minimum distances along or across the deck -> sep = separation[class_i-1][class_j-1] is the minimum gap in each of the four options.
Decision problem -> satisfaction, no objective. Search: domOverWDeg over turned, left, bottom with Luby restarts (inputOrder and minDom timed out on the 16x16 instances).
