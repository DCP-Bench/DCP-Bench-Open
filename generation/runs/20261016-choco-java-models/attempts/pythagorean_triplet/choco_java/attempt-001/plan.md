A Pythagorean triplet is a set of three natural numbers a < b < c -> a, b, c IntVars in 1..1000 with a < b < c (m.arithm)
a^2 + b^2 = c^2 -> aa = a^2, bb = b^2, cc = c^2 (m.square), aa + bb = cc (m.sum "=")
a + b + c = 1000 -> m.sum(a, b, c) = 1000
Print a, b, and c for this triplet -> output a, b, c
Objective: none (satisfaction)
