# Setup notes: clingo_asp

Built the clingo (ASP) integration from official Potassco documentation. One
setup attempt; no repair needed. Setup was frozen before any integration file
was written, as the skill requires.

## The decision this integration existed to test

ASP takes a logic program, not an object with fields, so none of the three
existing instance-conversion patterns fits unchanged. The choice made here, and
now the contract for every model this integration will accept:

- **The instance arrives as facts, generated by `run.py`.** A submission is a
  real `.lp` file, which is what a rosetta repository should hold, rather than a
  Python file that emits ASP. The conversion is generic and total — index
  positions first, value last — so `"demand": [250, 255]` becomes
  `demand(0,250). demand(1,255).` A field starting with a capital is lowered,
  since ASP reads a leading capital as a variable, and a collision is refused.
- **`#show` is the output contract.** `request.json` does not carry the declared
  output names, so the predicates a program shows are taken to be exactly its
  declared outputs. That keeps the contract inside the submission and needs no
  evaluator change.

## Chosen integration id

`clingo_asp`, not `clingo_python`. Submissions are `.lp` programs; naming the
integration after Python would misdescribe what the artifacts are. The earlier
setup-001 directory in this run was opened under the provisional name before
that was settled and holds no work.

## A limit worth recording

The readiness `isolation` check cannot be written as a submission here. This
image's clingo has no Python scripting — `#script(python)` raises "python
support not available" — so an ASP program cannot inspect its own container the
way a Python candidate can. The check drives the image directly under the
evaluator's own container flags instead. It tests the same guarantees on the
same image, but not through the ASP entrypoint, and `readiness_test.py` says so
at the top. Any future declarative integration, MiniZinc included, will hit this.
