Zebra puzzle: five houses, each array below maps an item (colour, nation, pet, drink, job) to its house 0..4; the five arrays use one fixed index order from the description.
five houses in a row, each painted a different colour -> distinct(*this, colors, IPL_DOM)
each inhabitant has a different nationality -> distinct(*this, nations, IPL_DOM)
each inhabitant owns a different pet -> distinct(*this, pets, IPL_DOM)
each inhabitant drinks a different beverage -> distinct(*this, drinks, IPL_DOM)
each inhabitant has a different job -> distinct(*this, jobs, IPL_DOM)
the painter owns the horse -> rel(jobs[painter] == pets[horse])
the diplomat drinks coffee -> rel(jobs[diplomat] == drinks[coffee])
the one who drinks milk lives in the white house -> rel(drinks[milk] == colors[white])
the Spaniard is a painter -> rel(nations[spain] == jobs[painter])
the Englishman lives in the red house -> rel(nations[england] == colors[red])
the snails are owned by the sculptor -> rel(pets[snails] == jobs[sculptor])
the green house is immediately on the left of the red one -> rel(colors[red] == colors[green] + 1)
the Norwegian lives immediately on the right of the blue house -> rel(nations[norway] == colors[blue] + 1)
the doctor drinks milk -> rel(jobs[doctor] == drinks[milk])
the diplomat is Japanese -> rel(jobs[diplomat] == nations[japan])
the Norwegian owns the zebra -> rel(nations[norway] == pets[zebra])
the green house is next to the white one -> rel(abs(colors[green] - colors[white]) == 1)
the horse is owned by the neighbour of the diplomat -> rel(abs(pets[horse] - jobs[diplomat]) == 1)
the Italian lives in the red, white or green house -> member(colors[red], colors[white], colors[green]) over nations[italy]
branching: all five arrays, INT_VAR_SIZE_MIN, INT_VAL_MIN (satisfaction, no objective, no redundancy needed)
