# four_numbers plan
x = [x1, x2, x3], each an integer in 1..10, one-hot per x_i (xv[i][v]), value = sum(v * xv[i][v]).
- "list of three integers between 1 and 10" -> one-hot domain 1..10, exactly one value per x_i.
- Subsets of {x1, x2, x3}: 7 nonempty subsets. Each subset gets a selector Bool s[n][S] per input number n.
- "every original number can be generated by summing subsets" -> for each input number n: at least one selector true, Or over the 7 subsets.
- "subset sums to n" -> If(s[n][S], sum of x_i in S == n) as a PB comparison over the integer expressions.
- Number list read from instance["numbers"] (length follows the instance; one instance has 3 numbers).
- Objective: satisfaction.
- Output x = [x1, x2, x3] as integer expressions.
