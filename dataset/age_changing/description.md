If you start with my age, in years, and apply the four operations +2, /8, -3 and *7 in some order, then the final answer you get is my husband's age.

Funnily enough, if you start with his age and apply the same four operations in a
different order, then you get my age.

Both ages are between 16 and 120, and every intermediate result is a positive integer, so a division by 8 must be exact.
