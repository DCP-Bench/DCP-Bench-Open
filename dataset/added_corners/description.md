Enter the digits 1 through 8 into the eight positions around the edge of a 3 by 3 grid whose centre is
empty, using each digit exactly once. The corners are circles (C) and the middles of the sides are squares (F):

```text
C F C
F   F
C F C
```

The number in each square must equal the sum of the numbers in the two circles adjoining it.

Print the values for each position (positions), starting from the top left corner and moving like reading a book, i.e., left to right, top to bottom.
