Hidato Puzzles start semi-filled with numbered tiles.
Connect the numbers together to win. Consecutive
number must touch horizontally, vertically, or
diagonally. The numbers must be in increasing order.
Fill in the empty cells, marked 0 in the given puzzle, with the numbers that
complete the puzzle, so that the grid holds each number from 1 to the number of cells exactly once.

Print the solved puzzle (x) as a list of lists of integers.
