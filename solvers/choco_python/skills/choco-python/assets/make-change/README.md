# Making change (all solutions)

**Problem:** Count the ways to pay 10 with any number of coins worth 1, 2 and 5.
**Shows:** a bounded integer per coin, a `scalar` equality, `find_all_solutions`, and a functional auxiliary variable (`total`) that is fixed by the counts, so it cannot repeat a solution.
**Run:** `python3 model.py`
**Expected:** `Ways to pay 10 with coins [1, 2, 5]: 10`
