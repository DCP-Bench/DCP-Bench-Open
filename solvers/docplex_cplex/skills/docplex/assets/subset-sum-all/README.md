# Subsets with a given sum (all solutions)

**Problem:** every subset of `[3, 5, 6, 7, 9, 11]` whose sum is 14.
**Shows:** binary decision list, linear equality, enumeration by no-good cuts over the decision binaries only, the final status `integer infeasible` as the only proof that the search is exhausted (anything else raises).
**Run:** `python3 model.py`
**Expected:** `Subsets of [3, 5, 6, 7, 9, 11] summing to 14: 3 (integer infeasible)`
**Expected:** `take [5, 9]`
