# Sudoku 4x4 (satisfy)

**Problem:** fill a 4x4 Sudoku so that every row, column and 2x2 box holds 1 to 4 once each, keeping the given digits.
**Shows:** satisfy with `solve()`, `intVarMatrix`, fixed cells with `arithm`, `allDifferent` on rows, columns and boxes, reading values with `getValue()` after a solve.
**Run:** `java Sudoku.java`
**Expected:** `Row 0: 1 2 3 4`
**Expected:** `Row 3: 4 3 2 1`
