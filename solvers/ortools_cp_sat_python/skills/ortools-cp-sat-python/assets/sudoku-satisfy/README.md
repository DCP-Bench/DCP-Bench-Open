# Sudoku (satisfy)

**Problem:** complete a 4x4 Sudoku with one solution: rows, columns and 2x2 boxes hold 1..4.
**Shows:** integer variables with domains, equality with constants, `add_all_different`, reading values after a satisfiable solve. A satisfaction problem has no objective; `OPTIMAL` means "a solution was found".
**Run:** `python3 model.py`
**Expected:** `OPTIMAL`
**Expected:** `1 2 3 4`
