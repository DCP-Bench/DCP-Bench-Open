# Pigeonhole (infeasible)

**Problem:** place 4 pigeons in 3 holes, one per pigeon, at most one per hole.
**Shows:** `add_exactly_one` and `add_at_most_one`, and how an infeasible model reports `INFEASIBLE` (not an error).
**Run:** `python3 model.py`
**Expected:** `INFEASIBLE`
**Expected:** `No assignment exists.`
