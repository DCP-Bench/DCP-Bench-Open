# SEND + MORE = MONEY (satisfy)

**Problem:** give each of the letters S, E, N, D, M, O, R, Y a different digit so that SEND + MORE = MONEY, with no leading zero.
**Shows:** a model with no parameter file, several scalar `find`s in one line, `allDiff` over a matrix literal, a linear equation, one solution printed with `-solutions-to-stdout` (variables come out in alphabetical order).
**Run:** `savilerow model.eprime -run-solver -solutions-to-stdout`
**Expected:** `letting M be 1`
**Expected:** `letting S be 9`
**Expected:** `letting Y be 2`
