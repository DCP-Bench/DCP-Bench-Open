# Latin square (satisfy)

**Problem:** complete a 4 x 4 Latin square from its first row, [3, 1, 4, 2].
**Shows:** data file (`data.dzn`), `all_different` on rows and columns, `satisfy`, printing a 2-D grid row by row.
**Run:** `minizinc --solver gecode model.mzn data.dzn`
**Expected:** `row 2: [1, 2, 3, 4]`
