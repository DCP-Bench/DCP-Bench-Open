# Graph colouring with fewest colours (minimise distinct values)

**Problem:** Colour the 10 nodes of the Petersen graph so that adjacent nodes differ, using as few distinct colours as possible.
**Shows:** minimising the number of distinct values: one Boolean per value marks whether it is used, and the objective sums them. The colour numbers need not be contiguous.
**Run:** `python3 model.py`
**Expected:** `Colours used: 3`
**Expected:** `proven optimal: True`
