# Knapsack, all optimal solutions

**Problem:** knapsack with weights 2, 2, 2, 4, values 3, 3, 3, 6, capacity 4. Optimum 6, achieved by 4 selections.
**Shows:** solving for the optimum, posting `objective == optimum` into a fresh solver, enumerating over the answer Booleans so each selection is printed once.
**Run:** `python3 model.py`
**Expected:** `All optimal solutions: 4`
**Expected:** `Optimum: 6`
