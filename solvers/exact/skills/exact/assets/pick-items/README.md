# Choose two items (all optimal solutions)

**Problem:** Choose exactly two of six items with values 4, 4, 3, 2, 4, 1, maximising total value.
**Shows:** `toOptimum` for a maximisation (negated result, so flip the sign), pinning the objective at its optimum with `addConstraint`, then enumerating optimal solutions.
**Run:** `python3 model.py`
**Expected:** `Optimal value: 8`
**Expected:** `Optimal solutions: 3`
