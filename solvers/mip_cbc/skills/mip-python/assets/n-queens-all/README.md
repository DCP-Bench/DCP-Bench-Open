# N-queens (all solutions)

**Problem:** Count the placements of 6 non-attacking queens on a 6 x 6 board.
**Shows:** satisfaction model (no objective), all-different through row, column and diagonal at-most-one constraints, enumeration with a no-good cut over the square binaries, infeasibility as the end of the loop.
**Run:** `python model.py`
**Expected:** `Solutions: 4`

With zero solutions the program prints `Solutions: 0` and no placement. With exactly one it prints `Solutions: 1` and that placement. Any printing format works for the placements.
