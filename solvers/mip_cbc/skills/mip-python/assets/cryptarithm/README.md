# Cryptarithm SEND + MORE = MONEY (satisfy)

**Problem:** Give each letter a different digit 0..9 so that SEND + MORE = MONEY, with S and M not 0.
**Shows:** one-hot binaries per letter and digit, at most one letter per digit, a weighted sum of letter values as one linear equation, reading a satisfied model's values.
**Run:** `python model.py`
**Expected:** `SEND + MORE = MONEY: 9567 + 1085 = 10652`
