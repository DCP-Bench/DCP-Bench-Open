# Colouring with the fewest colours (NValues objective)

**Problem:** colour the six nodes of a wheel (a five-cycle plus a hub joined to every rim node) so that adjacent nodes differ, using as few colours as possible.
**Shows:** `NValues` as the objective, `minimize(NValues(colour))`, and the proven optimum read with `bound()`.
**Run:** `python model.py`
**Expected:** `Colours: 4`
