# Magic square (all solutions, infeasible order)

**Problem:** fill an n x n grid with 1..n*n once each so that every row, column and both diagonals have the same sum.
**Shows:** `allDifferent`, `sum` over grid rows, columns and diagonals, `firstFailBinary`, counting every solution with `onSolution`, and an infeasible instance (order 2) reported by `isCompleted()` with zero solutions.
**Run:** `java MagicSquare.java`
**Expected:** `Order 3: 8 solutions, search completed: true`
**Expected:** `Order 2: 0 solutions, search completed: true`
