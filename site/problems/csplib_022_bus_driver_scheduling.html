csplib_022_bus_driver_scheduling

Description

This problem requires finding an optimal schedule for bus drivers. Given a set of tasks (pieces of work) to cover and a large set of possible shifts, where each shift covers a subset of the tasks, we must select a subset of shifts that covers each piece of work exactly once.  The goal is to cover all tasks while minimizing the total number of shifts used. The cost of each shift is considered equal.  Print a binary list indicating which shifts were selected (x) where 1 means the shift is selected and 0 means it is not.

Original model

python
import cpmpy as cp
import json

# Model definition
model = cp.Model()

# Decision Variables
# x[i] is a binary variable, 1 if shift 'i' is selected, 0 otherwise.
x = cp.boolvar(shape=num_shifts, name="x")

# Constraints
# Each task must be covered by exactly one selected shift (set partitioning).
for t in range(num_work):
    # For each task 't', find all shifts that cover it and sum their selection variables.
    covering_shifts = [x[i] for i in range(num_shifts) if t in shifts[i]]
    model += (cp.sum(covering_shifts) == 1)

# Objective
# Minimize the total number of shifts used.
model.minimize(cp.sum(x))

# Solve and print
model.solve()

solution = {"x": x.value().tolist()}
print(json.dumps(solution))
# End of CPMpy script
