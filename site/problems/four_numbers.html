Description

Given a list of up to four distinct integers between 1 and 10 (inclusive), the task is to find a list of three integers (also between 1 and 10, inclusive) such that all the original numbers can be generated by summing *subsets* of these three numbers.  For example, if the input is [1, 3, 7, 8], a valid solution is [1, 2, 5], because:  * 1 = 1 * 3 = 1 + 2 * 7 = 2 + 5 * 8 = 1 + 2 + 5  Print the list of three integers (x) that satisfies the above conditions.
